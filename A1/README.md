## Overview

This assignment explores pixel-based pattern generation using NumPy array operations. Two pattern families are produced:

1. A deterministic pattern based on a radial gradient combined with slicing-based stripe logic and a cross-shaped geometric intervention.
2. A stochastic pattern generated using Perlin noise and non-linear RGB channel mappings.

The goal is to investigate how simple array indexing, slicing, and controlled randomness can produce visually complex results.

---

## Method

### Example 01: Gradient, Stripes, and Cross Intervention

1. A radial distance field is generated from the image center and normalized to a grayscale gradient.
2. The gradient is mapped differently to the R, G, and B channels to introduce chromatic variation.
3. Stripe patterns are introduced using array slicing:
   - vertical red stripes
   - horizontal and vertical green bands
   - sparse blue stripes on the right third of the image
4. A cross-shaped region centered in the image is inverted using rectangular slicing.
5. The same cross region is then overwritten with white, creating a dominant geometric intervention.
6. An additional inversion based on the green channel modifies the blue channel response.

---

### Example 02: Perlin Noise and Channel Manipulation

1. A 2D Perlin noise field is generated using a fixed random seed for reproducibility.
2. The noise is normalized to the range [0, 255].
3. The noise is mapped to RGB channels using different scaling factors.
4. Integer casting to `uint8` is intentionally used to exploit wraparound behavior, producing non-linear color effects.
5. Variations are generated by selectively amplifying individual color channels.

## Discussion

The first example demonstrates how deterministic array slicing allows precise geometric control. The cross-shaped intervention shows how localized operations can dominate a global pattern.

The second example highlights the impact of randomness and numeric representation. The deliberate use of `uint8` wraparound introduces non-linear color behavior, which becomes more apparent when zooming into the images.

---

## Reproducibility

All random processes use a fixed seed (`SEED = 0`). Changing the seed regenerates new Perlin noise variations while preserving the same computational logic. Image resolution and parameters are explicitly defined in the script.
